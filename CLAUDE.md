# CLAUDE.md — pumperly-mcp

## Overview
MCP (Model Context Protocol) server that exposes any Pumperly instance to LLMs, enabling real-time fuel price queries, station search, route planning, and geocoding via JSON-RPC over HTTP or stdio transport.

## Tech Stack
- Go 1.24
- MCP protocol (JSON-RPC)
- Docker (multi-arch)
- npm package (stdio transport via `npx pumperly-mcp`)
- GoReleaser (`.goreleaser.yaml`)
- GitHub Actions CI

## Development
```bash
# Build
go build -o pumperly-mcp ./cmd/server

# Run (HTTP transport)
PUMPERLY_URL=https://pumperly.com ./pumperly-mcp

# Run (stdio transport)
npx pumperly-mcp

# Tests
go test ./...
```

## Architecture
- `cmd/server/` — Server entrypoint
- `internal/resources/` — MCP resource handlers (config, stats, exchange rates)
- `internal/tools/` — MCP tool implementations (find stations, routes, geocode)
- `client/` — Go client library for Pumperly API (`pumperly.go` + tests)
- `config/` — Configuration handling
- `docs/` — Documentation and images
- `glama.json` — Glama MCP directory metadata
- `server.json` — MCP server manifest
- `version/` — Version file

## Key Rules
- Never hardcode API URLs; configure via `PUMPERLY_URL` environment variable
- Docker image published to Docker Hub as `drumsergio/pumperly-mcp` with semver tags
- Also published to npm as `pumperly-mcp` for stdio transport
- Listed on Official MCP Registry, Glama, mcp.so, MCPServers.org, and ToolSDK
- HTTP transport listens on `127.0.0.1:8080` by default; use reverse proxy for network exposure
